# Portfolio demo data

Committed as ordinary (non-LFS) gzip-compressed CSVs (`pandas.read_csv`/`to_csv` handle `.csv.gz` transparently on Windows, Linux, and macOS, no extra tooling needed), so a normal `git clone` gets the real files directly. Generated by `data_portfolio_allocation.ipynb`, which only re-downloads from Yahoo Finance for a file that's missing; delete a file here and rerun that notebook to refresh it. `checksums.txt` records each file's SHA-256 as of the commit that added it, for verifying a copy obtained some other way.
